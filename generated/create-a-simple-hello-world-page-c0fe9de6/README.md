# Hello World Web Page

This is a simple static web page that displays the text "Hello World" as plain text with no interactive elements or additional UI.

## How to view

Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).

## Requirements met

- Displays "Hello World" as plain visible text.
- No other UI components or interactive elements.
- Loads successfully in standard browsers.

## Notes

This project contains only a single HTML file since the application requirements are minimal.

---
This is a static page and requires no backend, database, or deployment infrastructure by design.
