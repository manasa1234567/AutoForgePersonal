# Application Form Frontend

This React application provides a complete industry standard application form UI with header and footer, using Material-UI (MUI) components.

Setup:
- Run `npm install` to install dependencies.
- Run `npm start` to start the development server on http://localhost:3000

The frontend expects the backend API to be accessible at http://localhost:8000.

Form fields included match typical job application forms according to industry standards.

This UI is fully responsive and accessible.
