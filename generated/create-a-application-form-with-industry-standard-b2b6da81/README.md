# Application Form Project

This project is a full-stack application form built with React on the frontend, FastAPI on the backend, and styled with Tailwind CSS. The backend is prepared to accept form submissions.

## Frontend
- React with React Hook Form for form handling
- Tailwind CSS for styling
- Vite build system

## Backend
- FastAPI serving REST API
- Accepts form POST submissions

## Deployment
- Multi-stage Dockerfile builds frontend and backend
- Runs nginx to serve frontend + FastAPI on backend

## Usage
- Frontend runs on port 8080
- Backend API runs internally on port 8000

Details on how to run each part locally are in respective folders.
